Reference

SELECT ... FROM ... [WHERE ...] [GROUP BY ...] [ORDER BY ... [ASC/DESC]]

SELECT ... - the field(s) or calculated values to be displayed

  • AS - Change the name of a column being selected
  • If using GROUP BY, the following functions may be helpful;
    • SUM(attribute)
    • AVG(attribute)
    • COUNT(attribute)
    • MIN(attribute)
    • MAX(attribute)

FROM ... - the table(s) to be used

  • Can specify multiple tables separated by , and attributes from each can be referenced by TableName.Attribute

WHERE ... - the search criteria, which can contain the following:

  • CONTAINS
  • DOES NOT CONTAIN
  • EQUALS (=)
  • NOT EQUAL TO (!=)
  • GREATER THAN (>)
  • GREATER THAN OR EQUAL TO (>=)
  • LESS THAN (<)
  • LESS THAN OR EQUAL TO (<=)
  • AND
  • OR
  • NOT

GROUP BY ... - the field(s) used to group the returned rows

ORDER BY ... [ASC/DESC] - the field(s) that determine the sequence of the displayed results.

  • ASC is ascending (A-Z, 0-9)
  • DESC is descending (Z-A, 9-0)
